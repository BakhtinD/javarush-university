# ТЗ для проекта модуля 3

Ссылка на задание: https://javarush.com/quests/lectures/jru.module3.lecture04 

1. Технологический стек
```text
1) Сервлеты: Servlet API 4.0
2) JSP + JSTL - для динамических ваб-страниц
3) Работа с сессиями - хранить состояние пользователя
4) Maven - управление зависимостями
5) Архитектура MVC (Model-View-Controller) в упрощенном виде
6) Тестирование: JUnit + Mockito
```

2. План 
```text
1) Начнем с настройки проекта: создать правильную структуру каталогов
2) Добавить зависимости: подключить необходимые библиотеки
3) Написать бизнес-логику: реализовать игровую механику
4) Создать пользовательский интерфейс
5) Протестировать (UI + покрытие тестами)
```
3. Цель
```text
У нас должно быть полностью рабочее приложение, которое:
1) Принимает решение пользователя
2) Хранить состояние игры
3) Показать результат 
4) Соответствовать поддерживаемой архитектуре
```
